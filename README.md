DisTunnel is a python package for converting point clouds of rock exposures into Discrete Fracture Network models of their observed fractures. It was initially produced as part of Rufus Bloomfield's Master's thesis work at Aalto university in 2026, titled "DisTunnel: A Python package for converting Point Clouds to Discrete Frcture Networks". As of this time it is considered to be in relatively early development and is missing core intended functionality, but by the time of the 1.0 release it is intended that it will be capable of producing stochastic DFN realisations which include all fractures observed in a given point cloud as well as correctly generated background fractures
